ledgercheck demo

Checks of journal entries, AP invoices and AP payments that list items to check, each with a plain reason. They run in your browser.

Source code on GitHub

Your files are read in this page and nothing is uploaded. The page loads Python (Pyodide) and two wheels from this site only, and its Content-Security-Policy blocks any background request to another host. Links you click still open. You can check this in the browser's Network tab.

Loading the Python runtime. The first load downloads about 13 MB from this site.

Mode

The data is synthetic data from synthbiz, not real company data. Its amounts are uniform draws, so a Benford misfit on them means nothing. Precision and recall are scored against the labels synthbiz plants, and they do not predict results on real books.

Choose CSV files, then say which file is which table and which column is which field. Files must be UTF-8 CSV with a header row. Large files can run out of memory in a browser tab, so the page stops at 150 MB in total. The command line has no such limit.
