# Data sources and licenses

All data used by this repo is synthetic. It is generated by synthbiz. Nothing is copied from a real company, and the repo holds no real books.

## Where the data comes from

- examples/synthbiz-seed42-12m: made by synthbiz with seed 42, size small and 12 months. See examples/README.md.
- Tests, the benchmark and the evaluation make synthetic data in memory or in temporary folders with synthbiz, using fixed seeds.
- src/ledgercheck/measured.json: rates measured on synthetic data. It is labeled that way in the file and in every analysis that shows it.

Any match between a generated name and a real business is unintended.

## Rules that are computed, not copied

US federal holidays are computed by rule in src/ledgercheck/dates.py from the public law text, 5 U.S.C. 6103. That text is in the public domain. No outside calendar file is used.

## What is not in the data

- No real bank names, account numbers or tax ID numbers. The example files have no tax ID column, and a search for the pattern NN-NNNNNNN finds nothing in them.
- No claim that amounts, timing or anomaly rates match real-world statistics.
